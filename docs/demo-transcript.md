# prt demo transcript

This document describes the 13-second animation in [`prt.gif`](prt.gif). It is an alternative for readers who prefer not to view motion or cannot access the visual recording.

## Scene 1: live connections

The demo opens on the **Connections** section. A table lists TCP and UDP connections with their local port, known service name, protocol, state, PID, process, user, and age. The header reports the number of visible connections, whether root access is active, and estimated download and upload rates.

The selected connection is marked by a pointer. A **Details** panel below the table shows its local and remote addresses, interface, state, process command line, and all ports owned by the same process. The footer presents the most useful keyboard commands.

## Scene 2: process details and topology

Pressing `Enter` opens the selected entry in the **Processes** section. The detail view groups process metadata and associated network activity. Pressing `]` changes to the **Topology** sub-tab, which represents the relationship as a terminal tree from the process to local ports and remote endpoints.

## Scene 3: command palette

Pressing `:` opens the searchable command palette. The word `connections` is typed, its matching command is selected, and `Enter` returns to the Connections section.

## Scene 4: contextual actions

Pressing `Space` opens the contextual action menu for the selected connection. The available choices depend on the entry and can include terminating the process, copying connection data or the PID, blocking a remote IP address, tracing system calls, and creating an SSH forward.

No system-changing action is executed during the recording.

## Reproducing the recording

The animation is generated by [VHS](https://github.com/charmbracelet/vhs) from [`demo.tape`](demo.tape):

```sh
cargo build --release -p prt
vhs docs/demo.tape
```

The static README preview is a frame extracted from the same recording.
