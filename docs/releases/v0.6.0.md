## prt 0.6.0

Live network port inspection for macOS and Linux, with process details, SSH tunnel management and script-friendly output.

### Navigation changes

- `Tab` / `Shift+Tab` move between **Connections**, **Processes** and **SSH**; `[` / `]` switch sub-tabs.
- `Space` opens contextual actions. `o` / `O` select the sort column and direction; `K` and `c` remain direct kill/copy shortcuts.
- The bottom details panel is unified. Chart and namespace views and their old shortcuts were removed.
- Press `Esc` twice to clear a filter or discard a tunnel form. Press `?` for help and `:` for the command palette.

### Features and fixes

- SSH tunnel editing, inline validation, real status, uptime, command copying and automatic reconnect with exponential backoff.
- Listener health checks distinguish missing listeners and intermittent flapping, ignoring retained closed sockets.
- SOCKS/proxy listener detection, improved filtering, stable selection and process detail caching.
- External-command timeouts, platform guards and dependency security updates.
- Updated English, Russian and Chinese documentation and accessible demos.

### Install

```sh
# Cargo: Rust 1.88+
cargo install prt --version 0.6.0 --locked

# Homebrew: macOS arm64/x86_64 or Linux x86_64
brew install rekurt/tap/prt

# Download the corresponding attachment first (Linux x86_64)
sudo apt install ./prt_0.6.0_amd64.deb
sudo dnf install ./prt-0.6.0-1.x86_64.rpm

prt --version
prt --export json
```

Archives are provided for macOS arm64/x86_64 and Linux x86_64. Linux binaries require glibc 2.35+ (Ubuntu 22.04+, Debian 12+ or recent Fedora). Prebuilt packages do not require Rust. macOS scanning uses the built-in `lsof`; Linux scanning requires `/proc`.

Verify attachments with `sha256sum --check SHA256SUMS` (Linux) or `shasum -a 256 --check SHA256SUMS` (macOS), with all listed files present. SSH, tracing and firewall actions require their corresponding system tools and permissions.
