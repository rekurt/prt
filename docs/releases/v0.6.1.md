## prt 0.6.1

- Fix SSH forwarding to IPv6 targets, including addresses with a zone identifier.
- Refuse to overwrite malformed TOML configuration when saving tunnels.
- Restrict lifecycle filters to connection status; use `proc:gone` to search process names.
- Reject incompatible output modes and handle closed export/watch pipes cleanly.

Install with `cargo install prt --version 0.6.1 --locked`, or download the archive or Linux package for your platform. Rust 1.88+ is required for Cargo installation.

Verify downloaded attachments with `sha256sum --check SHA256SUMS` (Linux) or `shasum -a 256 --check SHA256SUMS` (macOS).
